# Основа для анализа истории игр (точные 4/4)

Сделал основу под твой сценарий:
- есть история из 1000+ игр;
- в каждой игре хранятся 8 навыков;
- твой выбор — последние 4 навыка;
- нужен подбор **лучших 4 навыков + героя** только по точным совпадениям 4/4.

## Что внутри

- `src/recommend_skills.py` — основной скрипт рекомендаций.
- `data/history_example.jsonl` — пример формата данных (можно заменить на свой файл).

## Формат данных

Поддерживаются обе формы (по одной записи на строку, JSONL).

### Вариант 1: список

```json
[76, 12, 7, 4, 8, 6, 5, 2, 1, 0, "Cherepaha"]
```

Расшифровка:
- `76` — id игры;
- далее 8 навыков;
- последние 4 (`6,5,2,1`) — твой выбор;
- `0/1` — поражение/победа;
- строка в конце — герой.

### Вариант 2: объект

```json
{"game_id": 76, "all_skills": [12,7,4,8,6,5,2,1], "result": 0, "hero": "Cherepaha"}
```

## Запуск

### 1) С аргументами (удобно)

```bash
python3 src/recommend_skills.py --input data/history_example.jsonl --blocked 9 10 11 12 13 --min-games 2 --top-k 5
```

### 2) Интерактивно (введет блоки сам)

```bash
python3 src/recommend_skills.py --input data/history_example.jsonl
```

## Что делает алгоритм

1. Берет только точные совпадения выбранной четверки (4/4).
2. Учитывает только те записи, где в выбранной 4-ке нет дубликатов навыков.
3. Отбрасывает четверки с заблокированными навыками.
4. Для каждой четверки выбирает лучшего героя по винрейту (при равенстве — где больше игр).
5. Показывает топ по винрейту и числу игр.

Если хочешь, следующим шагом добавлю режим:
- сначала 4/4, если мало игр — откат на 3/4 и 2/4 (как ты писал в комментариях к истории).


## Как добавить новые игры в историю

Твой файл истории — это **JSONL** (одна игра = одна строка).

### Шаг 1. Открой свой файл истории

Например:

```bash
nano data/my_history.jsonl
```

### Шаг 2. Добавь новую строку в конце

Формат как у тебя:

```json
[1020, 12, 4, 11, 10, 6, 5, 2, 1, 1, "Cherepaha"]
```

Где:
- `1020` — новый id игры;
- дальше 8 навыков;
- **последние 4** считаются твоим пиком;
- `1` или `0` — победа/поражение;
- последний элемент — герой.

Важно:
- каждая игра на **отдельной строке**;
- без запятых между строками (это JSONL, не JSON-массив);
- лучше не дублировать id игры.

### Шаг 3. Проверь, что файл читается

```bash
python3 src/recommend_skills.py --input data/my_history.jsonl --blocked 9 10 11 12 13 --min-games 2 --top-k 5
```

Если есть ошибка, скрипт покажет номер проблемной строки.

### Быстрое добавление одной игры из терминала

Можно дописать игру одной командой:

```bash
echo '[1021, 6, 10, 11, 7, 12, 9, 2, 3, 1, "Tank"]' >> data/my_history.jsonl
```

После этого снова запускай рекомендацию.
